# Floraia website

Static pages for the Floraia iOS app, served by GitHub Pages from the `main` branch:

- Home: https://mstcrypto01.github.io/floraia/
- Privacy Policy: https://mstcrypto01.github.io/floraia/privacy/
- Support: https://mstcrypto01.github.io/floraia/support/
- Terms of Use: https://mstcrypto01.github.io/floraia/terms/

Each page has English and Arabic sections. There is no build step: edit the HTML and push.
